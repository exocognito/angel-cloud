Angel Cloud documentation

An Angel is a policy-sealed, credential-custodied tool surface an agent reaches over MCP. These docs take you from an empty directory to a promoted Angel answering calls — driven by the management API and the published @smcllns/angel-core CLI. You never clone this repository.

Building this with an agent?

Point your agent at the two plain-text files below. They are stable, need no auth, and describe the whole journey without a repo checkout.

  • /SKILL.md — the create → publish → promote → connect journey as loadable instructions.
  • /llms.txt — a one-screen map of every doc and its URL.
